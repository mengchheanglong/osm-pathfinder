# OSM Data Directory

Place your OpenStreetMap `.osm.pbf` files here.

## Quick Start

Download Cambodia's road network (~50 MB):

```bash
curl -O https://download.geofabrik.de/asia/cambodia-latest.osm.pbf
```

Then move the file into this directory.

## Other Regions

Browse available extracts at [Geofabrik Downloads](https://download.geofabrik.de/).

> **Note:** `.osm.pbf` files are gitignored to keep the repository lightweight.
